# Web Interface Guidelines (distillado aplicado a este projeto)
Fonte: vercel.com/design/guidelines · github.com/vercel-labs/web-interface-guidelines (CC)
Regra do projeto: estas regras definem QUALIDADE, nunca IDENTIDADE (identidade = papel/tinta/fogo da marca).

1. Contraste medido por pixel (não por impressão): texto sobre papel ≥4,5:1; alvo p90 em zonas de texto.
2. Todos os estados desenhados: hover, focus-visible, active, disabled — nada "de fábrica".
3. Alvos ≥44px em touch; nav mobile sem alvos apertados.
4. Alinhamento deliberado (grade + ótico): captions alinhadas às molduras, números "fig." alinhados.
5. reduced-motion: estados finais visíveis, animações desligadas — nunca conteúdo escondido.
6. Animar wrappers/transform (GPU), nunca propriedades de layout; sem scroll-jack.
7. Fontes: subset, self-host, font-display:swap; uma família (Fraunces) com eixos ópticos.
8. Aspas tipográficas « » e — em Français; tabular-nums onde houver números.
9. Sem dead-ends: todo link leva a algo real (Instagram real, âncoras reais).
10. Mobile é composição própria, não redução.
